🤖 AI Coding Tools

IDE / Editor

- "Cursor" (https://cursor.com) — AI 기반 코드 에디터
- "GitHub Copilot" (https://github.com/features/copilot) — GitHub의 AI 코딩 도구
- "Windsurf" (https://windsurf.com) — AI 기반 개발 환경

CLI / Coding Agents

- "Claude Code" (https://www.anthropic.com/claude-code) — Anthropic의 에이전틱 코딩 도구
- "OpenAI Codex" (https://openai.com/codex/) — OpenAI의 코딩 에이전트
- "Gemini CLI" (https://github.com/google-gemini/gemini-cli) — Google의 오픈소스 AI 에이전트
- "Aider" (https://github.com/Aider-AI/aider) — 터미널 기반 오픈소스 AI 페어 프로그래밍 도구

App Builders

- "Lovable" (https://lovable.dev) — 자연어 기반 웹 앱 빌더
- "Replit" (https://replit.com) — AI 기반 앱 개발 및 배포 환경
- "v0" (https://v0.dev) — Vercel의 AI 웹 개발 도구

🚀 Made with Vibe Coding in Korea

한국 빌더들이 AI 코딩 도구를 활용해 만든 실제 앱과 서비스를 모읍니다.

단순 프로젝트 나열보다는 실제 공개되어 사용해볼 수 있는 서비스를 중심으로 추가합니다.

- "이득체크" (https://ideukcheck.com) — 사는 곳과 나이, 가구 소득을 고르면 지금 받을 수 있는 정부·지역 혜택을 판정하고, 둘 중 뭐가 더 이득인지 내 숫자로 계산해 주는 웹앱. 가입이 없고 입력값은 브라우저에만 남습니다. 공공데이터와 공식 고시 원문으로 만든 1인 프로젝트입니다.

👉 "VibeCrew 앱 출시 게시판" (https://vibecrew.kr/ship)

🙌 Contributing

이 리스트는 VibeCrew만을 위한 목록이 아닙니다.

한국 바이브코딩 생태계에 도움이 되는 다음 자료를 환영합니다.

- 바이브코딩 커뮤니티
- 한국어 튜토리얼 및 가이드
- AI 코딩 도구
- 바이브코딩으로 만든 실제 서비스
- Build in Public 기록
- 행사 및 모임

빠진 자료가 있다면 Issue 또는 Pull Request로 알려주세요.

특정 서비스나 커뮤니티에 한정하지 않고 한국 바이브코딩 생태계에 유용한 공개 리스트를 함께 만들어가는 것을 목표로 합니다.
